# Disease Diagnosis Assistant

Проект по классификации заболеваний на основе текстовых описаний симптомов с использованием модели BERT. Обучение проводилось на комбинации стандартного датасета "болезнь-симптомы" и данных, собранных с Reddit, где пользователи описывают свои симптомы в свободной форме. Также реализован Telegram-бот для удобного взаимодействия с моделью.

## Что делает проект

Пользователь вводит описание своих симптомов обычным текстом, а модель предсказывает наиболее вероятное заболевание. Основная фишка в том, что модель обучена не только на формальных медицинских описаниях, но и на реальных постах людей с Reddit, поэтому она лучше понимает разговорные и нестандартные формулировки.

## Структура проекта

- Парсинг данных с Reddit через Reddit API (praw)
- Извлечение симптомов из постов с помощью GPT API
- Объединение Reddit-данных со стандартным датасетом
- Аугментация данных (перестановки симптомов)
- Обучение модели BERT (bert-base-uncased) на классификацию заболеваний
- Telegram-бот для взаимодействия с моделью

## Результаты

| Датасет | Accuracy | Precision | Recall | F1 Score |
|---|---|---|---|---|
| Стандартный | 1.0000 | 1.0000 | 1.0000 | 1.0000 |
| Reddit | 0.6292 | 0.6291 | 0.6292 | 0.6225 |
| Объединенный | 0.7560 | 0.7668 | 0.7560 | 0.7572 |

Объединенный датасет дает лучшие результаты на неформальных описаниях по сравнению с моделью, обученной только на стандартных данных.

## Используемые технологии

- Python
- BERT (Hugging Face Transformers)
- praw (Reddit API)
- OpenAI GPT API
- Telegram Bot API

## Как запустить

1. Клонировать репозиторий

```bash
git clone https://github.com/sk3feel/coursework-health-nlp.git
cd coursework-health-nlp
```

2. Установить зависимости

```bash
pip install -r requirements.txt
```

3. Настроить API ключи для Reddit и GPT в конфигурационном файле

4. Для сбора данных с Reddit запустить скрипт парсинга

5. Для обучения модели запустить скрипт обучения

6. Для запуска Telegram-бота указать токен бота и запустить соответствующий скрипт

## Важно

Проект носит исследовательский характер и не является сертифицированным средством диагностики. Результаты модели не заменяют консультацию врача.
